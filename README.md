# Xưởng 2 — mô hình 3D (bản R30)

Trang xem 3D mặt bằng xưởng: khung nhà, sàn lửng, bố trí máy, tuyến cáp nhôm vặn xoắn ABC 4×35
treo theo cột và ba tủ phân phối khu vực.

Xem trực tiếp: https://tcl-da.github.io/xuong2-3d/

- Chuột trái xoay · lăn chuột zoom tại con trỏ · giữ chuột giữa/phải di chuyển · bấm đúp bay tới chỗ trỏ.
- Bảng **Hiện / ẩn chi tiết** góc trái: tắt bớt lớp cho đỡ rối; nút “Chỉ xem cáp”.
- Lớp **Độ dài từng đoạn cáp**: hiện số mét từng nhịp.
- Nút **Tải mô hình 3D (GLB)** cuối thanh công cụ: tải file  (13 MB) để mở bằng Blender, Inventor, 3D Viewer của Windows…

Số đo có dấu `*` là đọc từ ảnh hoặc gán tạm, chưa kiểm chứng hiện trường.

Thư viện three.js lấy từ CDN jsdelivr (r160). Mô hình sinh bằng CadQuery, dữ liệu trong `scene_R30.json`.
